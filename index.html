Empirical Methodology Invariants

💥 Physical Process Fault Injection

Processes execute as real OS child subprocesses and are terminated abruptly midway through atomic operations using non-maskable SIGKILL (taskkill /F /T on Windows).

⚡ Zero-API Synthetic Harness

Eliminates cloud latency, billing spikes, and rate-limiting flakiness by evaluating execution state transitions deterministically in under 15 seconds.

💸 Token Waste Accounting ($W_{token}$)

Re-executed tool invocations on resumed tasks are tracked as duplicated waste tokens ($W_{token}$), penalizing architectures that lose execution state.

🛡️ State Corruption Detection

Verifies whether mid-task terminations leave broken AST files, corrupted JSON journals, or unreleased lock files on disk.
