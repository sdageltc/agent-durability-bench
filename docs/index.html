💥 6 Real-World Failure Scenarios

DCP-1.0 subjects agent architectures to 6 physical fault injection vectors across 400 test executions:

⚡ 1. Mid-Epoch SIGKILL

Process terminated with non-maskable OS SIGKILL midway through executing an atomic AST refactor step.

WAL: 100% | Snapshot: 100% | In-Mem: 0%

🧠 2. Subprocess OOM Crash

Simulates out-of-memory container termination during large whole-file diff generation and memory spikes.

WAL: 100% | Snapshot: 100% | In-Mem: 0%

☁️ 3. Spot Instance Eviction

Zero-warning VM termination during multi-turn LLM generation and tool call processing.

WAL: 100% | Snapshot: 85% | In-Mem: 0%

🐍 4. Unhandled Runtime Bug

Unhandled Python exception during agent self-evolution loop; tests recovery from recorded journal history.

WAL: 100% | Snapshot: 100% | In-Mem: 0%

🔒 5. Atomic Lock Contention

Crash occurs while holding state file locks; verifies atomic rename and zero orphan .tmp lock leakage.

WAL: 100% | Snapshot: 90% | In-Mem: 0%

🎯 6. 10-Step Macro Goal Resumption

Crash injected at Step 8 of a 10-step goal; measures whether steps 1–7 are skipped to prevent duplicate token costs.

Waste: WAL 0.0% vs Snapshot 14.5%

🔬 Reproduce Locally

Run the complete 400-task synthetic durability benchmark locally in under 15 seconds without paying cloud LLM API tokens: 

# Clone and run DCP-1.0 benchmark matrix
git clone https://github.com/sdageltc/agent-durability-bench.git
cd agent-durability-bench
pip install -e .
durability-bench --matrix --export-json results/leaderboard.json
